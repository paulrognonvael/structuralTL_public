This repository gathers the code and simulation output for our structural transfer learning algorithm to improve feature selection in high-dimensional linear regression.

Content:

simulations/routines.sim.app.R gathers functions used across simulations and the colon cancer example.
simulations/simulation.data.R is code used generate data for the simulation study
simulations/sim.TL.R is code used for the simulation study
simulations/report.R is code used to generate plots and summaries from simulation output.
colon cancer/coloncancer.R is code used for the colon cancer example.
